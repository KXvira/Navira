# Kabarak prototype data

`kabarak-prototype.navmap.json` is a 131,864 byte feasibility package derived from a single OpenStreetMap API 0.6 raw-data bbox request on 2026-10-07: west 35.958, south -0.174, east 35.973, north -0.158. It contains 75 tagged road ways and 280 tagged building ways. It has no terrain, labels, icons, fonts, glyphs, sprites, remote styles, or tile URLs. It is a small rendering test, not a complete or current navigation map.

The app displays attribution when the package is loaded. No public OSM raster tile service was used.
