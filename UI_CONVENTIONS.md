# UI conventions

Navira uses a dark navy canvas (`#08131f`), white primary text, muted blue labels, green for current reliable status, and amber for stale, unavailable, or low precision status. Expo Router supplies one compact header per screen. Tab content does not add a second title or top safe-area inset beneath that header. Tabs use text labels without an icon font; controls have clear accessibility labels and primary touch targets are at least 44 pt high.

The Location screen has a compact status panel and responsive measurement cards. Freshness and reported horizontal accuracy are separate: a fresh update with accuracy above 100 m is amber and explicitly marked low precision, while the original number remains visible. Missing accuracy is never treated as zero. This display threshold does not affect waypoint saving or freshness. Waiting, receiving, stale, permission-denied, services-disabled, and error remain distinct. Last measurements remain visible with their age when stale.

The Satellites tab uses a virtualized, compact row list. It shows Android GNSS phase, age, reported count, and used-in-fix count above the list. Counts and rows are hidden when a snapshot is stale. An accessible Info action explains C/N₀ and the limits of GNSS provenance; Expo Go shows native diagnostics as unavailable without affecting location readings.

The Waypoints tab keeps a Save action and saved-place list near the top. A selected destination appears as a compact summary that opens a focused guidance view. Guidance shows straight-line distance, initial true-north bearing, and current/saved reported accuracies. It pauses when current location is stale or unavailable. Waypoint detail viewing, editing, and saving are separate stack routes. Deletion always uses a platform confirmation alert. Longer technical explanations are available through accessible Info actions.

The Routes tab has a compact unfinished-recording entry and a virtualized saved-route list. The focused recording screen shows state, active time, confirmed stored samples, distance-contributing points, observed low-precision duration, and estimated distance, followed by Start/Pause/Resume/Stop/Save controls as applicable. It explains foreground-only behavior and requires explicit resume after lock or background. The saved-route detail screen shows sample exclusion reasons and explains that GPX omits excluded samples. Storage errors remain visible; no count is presented for an uncommitted point.

The map keeps offline coverage controls in a compact expandable panel. Its collapsed state shows missing, inside, or outside coverage for the map center; when available, it separately reports whether the current location is outside the selected package. The expanded list shows each package's name, bounds, actual storage size, source, and selection state. Removal uses a platform confirmation alert. Invalid package files are counted and retained, with errors and Retry visible. Attribution remains visible whenever a package is selected.

## Brand assets

The Navira mark is a northeast navigation pointer inside a broken satellite orbit. Its editable source is `assets/brand/navira-mark.svg`; `node scripts/render-brand.js` reproduces the local PNGs and the review preview. The palette is navy `#08192B`, mint `#5BF1BE`, cyan `#3BCDEB`, and off-white `#F2FCFF` for the themed monochrome mask. The app's existing screen canvas remains `#08131F`.

`assets/icon.png` is the 1024 px square app icon. Android uses the transparent `android-icon-foreground.png` over the solid navy `android-icon-background.png`, with the mark inside the centered adaptive safe area. `android-icon-monochrome.png` is a transparent white silhouette so Android can apply the launcher theme. `splash-icon.png` is the same mark on transparency; the native splash uses a navy background and a centered 180 dp image. Android's system splash controls the display area and timing, so the artwork does not fill the screen and no artificial delay is added. `favicon.png` supplies the retained web target. None of these assets require a remote font, glyph, icon, or image request. Review `assets/brand/navira-preview.png` before requesting the next APK build.
